Privacy policy

This policy covers Award Atlas — Cathay award search and this download website, published by SOMOMENTOUS LLC.

Search information

The extension handles your selected airports, dates, cabin, adult traveler count, filters, named saved searches and normalized availability results. It reads temporary booking parameters from your selected Cathay page to run searches. It does not ask for or read your password and has no permission to read Chrome’s cookie store. Chrome sends your existing cookies directly to Cathay with same-origin requests. Temporary booking parameters and raw availability responses are not persisted in extension storage.

Where information goes

Your requested searches go directly to the HTTPS hosts www.cathaypacific.com, api.cathaypacific.com and book.cathaypacific.com. Search data and Cathay session information are not sent to a developer-operated server, advertising provider or analytics service. The extension does not monitor other sites or build a browsing-history profile. Airport autocomplete uses a bundled public-domain OurAirports catalog and sends no lookup query over the network.

Local storage

From version 0.4.0, preferences, named search configurations, and your latest normalized search results/progress are stored in Chrome extension local storage and persist across restarts and updates when the same extension identity is retained. Named searches contain choices rather than result snapshots. Temporary tab/document IDs and active-job state live in extension session storage. A restored unfinished search is paused and needs a new Cathay booking session before continuing.

Clear results removes the stored search/results; delete saved searches individually. Removing the extension deletes its local data. Data is not synchronized across devices. Earlier 0.3.x results used session storage only and are cleared by Chrome on update/reload. Signing out on Cathay ends its login separately. Cathay’s page can observe the panel content rendered on it.

Terms agreement

The extension stores the accepted terms version, a fingerprint of the terms text, and the acceptance time in local extension storage. This record stays in your browser and is not sent to the publisher. Changes to the terms text require agreement again. Removing the extension or clearing its local storage removes the acceptance record.

Updates and version policy

At startup, approximately every six hours, and on manual checks, the extension requests public release metadata from api.github.com and a public JSON version policy from raw.githubusercontent.com. These requests contain no Cathay search, account or session information and no GitHub credentials. GitHub necessarily receives ordinary connection information, such as your IP address. Release versions/notes, cache validators, check times, errors and the last validated policy are cached locally. A valid minimum-version policy can require an update; network failure alone does not block use. Update Now opens GitHub Releases. ZIP upgrades require manual file replacement and Chrome Reload.

Permissions

Storage retains the local information described above. Scripting opens the panel and performs search operations in the selected Cathay tab. Alarms schedules update checks. Host access is limited to the three Cathay hosts and the two GitHub metadata hosts above. Content scripts run only on Cathay. All executable extension code is packaged locally; remote data is never executed as code.

Data use and help

Information is used to provide search, saved-search and update functionality. It is not sold, used for advertising, or transferred for unrelated purposes. The publisher cannot retrieve your local searches through a backend. For help, use GitHub issues. Issues are public: include only the version and a sanitized error description, never passwords, cookies, session IDs, membership or payment details. GitHub processes what you choose to post under its own policies.

This website

The download website and release assets use GitHub Pages and GitHub Releases. GitHub processes request information to deliver and secure those services under its privacy statement. The legacy support site is hosted by Cloudflare under its privacy policy. These static pages add no advertising, forms, visitor analytics or cookies. Opening an external link is a separate request to its host.

Changes

Changes to these practices will be reflected here and in release notes. OurAirports data is public domain; attribution is included in the extension package.
