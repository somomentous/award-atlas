Privacy policy

This policy covers the Award Atlas — Cathay award search Chrome extension, published by Nathan Tia, and this download website. Contact: ntia78@gmail.com.

What the extension handles

  • Search choices: origin and destination airports, departure dates or month, cabin, adult traveler count, and result filters.
  • Cathay website information: the current Cathay tab's URL and loading state, temporary booking parameters including a booking-session identifier, and availability responses. These are used only to run your requested searches on Cathay.
  • Search results and progress: normalized flight segments, times, reported cabin inventory, checked dates, error status, and panel visibility. Other fields in Cathay's raw responses are not retained in extension storage.

The extension does not ask for or read your password, and has no permission to read Chrome's cookie store. Chrome sends your existing Cathay cookies directly to Cathay with same-origin requests. Temporary booking parameters are used in memory and are not saved in extension storage or sent to the developer.

Where data goes

When you start or continue a search, the extension sends the necessary search and booking parameters directly to Cathay's HTTPS sites: www.cathaypacific.com, api.cathaypacific.com, and book.cathaypacific.com. Cathay processes those requests under its own policies. Award Atlas does not send your search, booking session, raw responses, or results to a developer-operated server, analytics provider, advertising service, or data broker. It does not monitor other websites or build a browsing-history profile.

Local storage and deletion

Your latest query, normalized results, checked dates, panel state, and internal tab/document identifiers are stored in Chrome's extension session storage so progress survives a page redirect or extension-worker restart. Temporary booking parameters and raw responses are not stored. Clear results removes the stored search when no search or required waiting period is active. Chrome clears this session storage when the browser restarts or the extension is reloaded, updated, disabled, or removed. Signing out on Cathay ends your Cathay session separately.

Flight results are rendered on Cathay's page inside the panel; the page can observe the rendered panel content. No saved itinerary list is synchronized between devices.

Permissions

Storage retains the local search and panel state. Scripting opens the panel and reads booking parameters or requests availability in your selected Cathay tab. Host access is limited to the three Cathay domains above. Executable extension code is packaged locally; no remote executable code is loaded.

Extension updates

Chrome Web Store installations receive updates through Chrome. ZIP installations require downloading a new ZIP, replacing the local extension files, and reloading the extension manually. The panel can ask Chrome for an update check when you choose Check for updates. This uses Chrome’s built-in update service and does not send your Cathay session or searches to the publisher. The installed version, pending update version, and last manual-check time are stored in extension session storage. Chrome handles update-service requests under Google’s policies. Updating the extension clears session results.

Limited use

Award Atlas's use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only to provide the extension's award-search functionality. It is not sold, used for advertising, transferred for unrelated purposes, or used to determine creditworthiness or for lending. The developer cannot access the extension's locally stored searches through a backend.

Support and this website

If you email support, the publisher and email provider receive your email address and the information you choose to send. Support correspondence is used to respond to your request and investigate reported issues. Please do not send passwords, cookies, booking-session identifiers, or payment information. You may request deletion of support correspondence by emailing the address above, subject to any applicable retention obligations.

This static download website is hosted on GitHub Pages, and extension downloads are hosted on GitHub Releases. GitHub processes request information, including IP addresses, to deliver and secure these services under its privacy statement. The linked support website is hosted on Cloudflare under its privacy policy. This download website adds no cookies, analytics scripts, forms, or advertising. The extension does not contact this website unless you open a link to it. Google separately processes Chrome Web Store activity under its own policies.

Changes

Updates will be published here with a revised date. Material changes to the extension's data practices will also be disclosed as required by the Chrome Web Store.

Award Atlas is independent of Cathay Pacific and Asia Miles.
